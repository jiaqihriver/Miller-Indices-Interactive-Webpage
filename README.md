# Miller-Indices-Interactive-Webpage
一个单文件、可离线运行的交互教学页面，用来讲**晶体学中的米勒指数（晶向与晶面）**。

- **主文件**：`miller-indices.html`（约 100 KB，单文件）
- **打开方式**：双击即可用浏览器打开。不需要联网、不需要装任何东西、不需要服务器。
- **拷走即用**：整个文件可以直接发给别人、拷进 U 盘、放进自己的博客或课程网盘。

> 内容依据 `Miller Indices for Crystal Directions and Planes.pdf` 整理，只保留知识本体
> （记号、坐标系、点、晶向、晶面、晶向族/晶面族、例题、自测），剔除了原文的设计理念与参考文献。

## 1. 五分钟上手

1. 双击 `miller-indices.html`，默认停在第 01 页。
2. **左边点标题**切页，或按 **`→`** 翻到下一页。共 16 页。
3. 图里**按住拖动** = 旋转晶胞；**滚轮** = 缩放；**双击图面**或点右上角 `⟲ 还原` = 复位。
4. 页面右侧的输入框随便改（比如把晶向的 `u` 改成 `2`），左边的图和公式会**当场变**。
5. 投影上课前，点右上角切到 **浅色主题**。

## 4. 图怎么操作

页面上 **18 张图**都能转（含晶面族那一组缩略图）。

| 动作 | 效果 |
|---|---|
| **拖动图面** | 旋转晶胞（六方俯视图是平面内旋转） |
| **滚轮 / 双指捏合** | 缩放，范围 0.5×–3.2× |
| **`Shift` + 拖动** | 平移 |
| **双击图面** | 这一张图恢复初始视角 |
| **右上角 `⟲ 还原`** | 同上；视角被改过时按钮会变成**高亮蓝色** |
| **顶栏 `⟲ 全部还原`** | 一次把所有图复位 |

两点要注意：

- **鼠标在图面上时，滚轮是缩放而不是滚动页面**。想滚页面就把鼠标移出图外。
- 晶面族那一排缩略图**共用一个视角**：转任意一张，整组跟着一起转。

## 5. 每一页能做什么（内容地图）

| 页 | 主题 | 可以动手的地方 |
|---|---|---|
| 01 | 记号速查 | 5 个按钮切换 `(1,1,1)` 点 / `[111]` 晶向 / `⟨111⟩` 晶向族 / `(111)` 晶面 / `{111}` 晶面族，看同一组数字在不同括号下指什么 |
| 02 | 坐标系与原点 | **立方晶系 ⇄ 六方晶系**切换，六方给底面俯视图，直观看到 a₁、a₂ 夹角 120° |
| 03 | 晶格中的点 | 输入 x/y/z（支持分数），点实时落进晶胞；4 组预设按钮 |
| 04 | 晶向 `[uvw]` | 输入 u/v/w + `±` 取反 + 7 组预设；**公式条实时演示「×最小公倍数」的化简**；负指数自动画出邻胞虚线框 |
| 05 | 晶面 `(hkl)` | 输入三条轴的截距（可填 `∞`/`inf`）；**三步法读数条实时走完「截距 → 取倒数 → (hkl)」**；7 组预设 |
| 06 | `[hkl]` ⟂ `(hkl)` | 输入 h/k/l，同一张图里同时画晶面和垂直晶向，并给出点积与夹角 |
| 07 | 晶向族 `⟨uvw⟩` | `⟨100⟩` / `⟨110⟩` / `⟨111⟩` 一键高亮全族（6 / 12 / 8 个方向） |
| 08 | 晶面族 `{hkl}` | 三个族逐个看，缩略图列出每个成员（6 / 12 / 4 个面） |
| 09 | 立方 vs 四方 | 并排对比 `a=a=a` 与 `a=a≠c`，看 `[001]` 为什么会从 `⟨100⟩` 里分裂出去 |
| 10 | 例 1 · 画出三个晶向 | 「举一反三」可换 `[010]` / `[101]` / `[111]` 重画 |
| 11 | 例 2 · 读出晶向 | `显示答案`；再试「反向」「把原点挪到前右上」 |
| 12 | 例 3 · 点坐标与晶向指数 | 切换**原点位置**（后左下角 / 前右角），同一题看出两种答案 |
| 13 | 例 4 · 两个方向的公共晶面 | 三步按钮：`① 两个晶向 → ② 公共平面 → ③ 检验`；举一反三用叉乘自动求法向 |
| 14 | 例 5 · (110) 与 (220) | 一张图里叠画两个平行面，看「平行但不等价」 |
| 15 | 例 6 · 六方晶格 | 开关 `(110) 面迹` 与 `a₃ 轴`，看 [110] 与面迹的垂直关系 |
| 16 | 自测练习 | 随机出题：`看图写晶向` / `看图写晶面`；`检查` 判分、`看答案` 不计分；统计连对与得分 |

## 6. 输入格式

| 想输入 | 这样写 |
|---|---|
| 分数 | `1/2` `2/3` `-1/4`（也接受小数 `0.25`） |
| 无穷（与该轴平行） | `inf` 或 `∞` 或留空 |
| 负数 | 直接打 `-2`，或点输入框旁的小按钮 `±` |
| 化简不出来的数 | 例如 `0.1234` → 自动显示为 `0.123`，不会吞成 0 |

**负号写法按晶体学惯例自动区分**：

- 讲**点**和**截距**时用普通负号：`(-½, ⅔, 1)`
- 讲**晶向 / 晶面指数**时用上划线：`[1̄10]`、`(3̄20)`

## 9. 给讲课用的几点建议

- **顺序就是设计好的讲解顺序**，从 01 一路 `→` 到 16 即可，每页一屏不用滚。
- **每个例题一页**，讲完一题按 `→` 进下一题，节奏很稳；「查看解析」折叠着，可以让学生先想再展开。
- **数字是可以现场改的**：比如讲晶面时把截距从 `1` 改成 `2`，让学生看着 `(110)` 变成 `(220)`；
  讲晶向时把 `u` 从 `1` 改成 `2/3`，看化简过程。比放静态图效果好得多。
- **旋转用来破误解**：学生分不清 `(100)` 和 `(001)` 时，把晶胞转一下，让面「立起来」就清楚了。
- **第 16 页可以当随堂练习**：投出来让学生报答案，当场 `检查`。
- 讲完一轮想恢复原状：顶栏 `⟲ 全部还原`。

## 10. 想改内容 / 二次开发

文件是一个自包含的 HTML，结构很规整。用任何文本编辑器打开即可改。

**加一页**：复制一节 `<section class="page" id="sXX" data-title="标题">…</section>`，
改掉 `id` 和 `data-title` 就行——左侧导航、翻页条、页码统计**都会自动更新**，不用改 JS。
可选属性：`data-nav="短标题"`（导航里显示短一点）、`data-group="分组名"`（归到某个分组标签下）。

**改配色**：`<style>` 顶部有两组 CSS 变量，`:root` 是深色、`html[data-theme="light"]` 是浅色。
改 `--accent`（主色）/ `--accent2`（副色）/ `--line`（分隔线）就能换整体风格。

**改内容**：正文就是普通 HTML。数学记号用几个现成的 class：

| class | 效果 | 例子 |
|---|---|---|
| `.m` | 数学体（衬线、不换行） | `<span class="m">[100]</span>` |
| `.bar` | 上划线（负号） | `<span class="bar">1</span>` → 1̄ |
| `.frac` | 上下叠放的分数 | `<span class="frac"><i>1</i><s>2</s></span>` |
| `.tag` / `.tag.a` / `.tag.b` | 小标签 | `<span class="tag a">例 1</span>` |
| `.step` | 左侧竖线的编号列表 | `<ol class="step"><li>…</li></ol>` |
| `.note` | 左侧竖线的提示块 | `<div class="note">…</div>` |
| `details` / `summary` | 可折叠块（解析、举一反三） | `<details><summary>查看解析</summary>…</details>` |

**外部控制接口**：页面把控制器挂在了 `window.MI` 上，可以在浏览器控制台里驱动它：

```js
MI.show('s8d')        // 跳到指定页
MI.step(1)            // 下一页；step(-1) 上一页
MI.resetAll()         // 全部图复位
MI.pages              // 16 个页面的 DOM 节点
MI.views              // 18 张图的视角状态（{view:{az,el,zoom,...}}）
```

## 11. 常见问题

| 现象 | 原因 / 处理 |
|---|---|
| 图转不动 | 要按住**图面本身**（压到文字或按钮上无效）；换 `Shift`+拖动可以平移看看 |
| 页面滚不动了 | 鼠标正停在图上，滚轮被缩放吃掉了——把鼠标移到图外再滚 |
| 翻页条挡住内容 | 它是吸底的。滚一下，或先把图缩小（滚轮往下滚） |
| 想回到初始画面 | 单图点 `⟲ 还原`；全部点顶栏 `⟲ 全部还原`；双击图面也行 |
| 输入框里改不了数字 | 点一下输入框先聚焦；`∞` 可以打成 `inf` |
| 拖完图讲解对不上位置 | 顶栏 `⟲ 全部还原`，一秒回到标准视角 |
| 提示 `color-mix` 相关的样式不对 | 浏览器太旧。用 Chrome / Edge / Safari / Firefox 的近期版本 |

**关于打印**：因为是分页的，直接打印只会输出当前这一页。要打印全部内容做讲义的话，
先在控制台运行一次 `MI.pages.forEach(p => p.classList.add('on'))`，再 `Ctrl/⌘ + P`。
